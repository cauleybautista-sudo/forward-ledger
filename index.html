Mathematical Calibration & Methodology

The Football Tracker model operates on append-only pre-kickoff predictions graded strictly against full-time results. The core philosophy mandates that probability calibration, not raw win-rate, governs model superiority.

1. BRIER SCORE (BS): BS = (1/N) * Σ (p_i - y_i)^2 Where p_i is the model forecast probability and y_i ∈ {0, 1} is the binary realization. A Brier Score below 0.2000 represents elite international match calibration. 2. EXPECTED VALUE & HIT CONVERGENCE: Expected Hits = Σ p_i Net Performance Variance = Actual Hits - Expected Hits When Actual Hits > Expected Hits, the model displays positive variance and healthy conservatism. 3. GOAL EXPECTATION & DIXON-COLES ADJUSTMENT: P(X=x, Y=y) = τ(λ, μ) * (e^-λ * λ^x / x!) * (e^-μ * μ^y / y!) Corrected for low-score correlation (0-0, 1-0, 0-1, 1-1) in international tournament play. 4. CLOSING LINE VALUE (CLV): CLV = (Closing Odds / Stated Odds) - 1.0 Systematic positive CLV demonstrates statistical edge against market consensus pricing.
