Mathematical Calibration & Methodology

The Football Tracker model operates on append-only pre-kickoff predictions graded strictly against full-time results. The core philosophy mandates that probability calibration, not raw win-rate, governs model superiority.

1. BRIER SCORE (BS): BS = (1/N) * Σ (p_i - y_i)^2 Where p_i is the model forecast probability and y_i ∈ {0, 1} is the binary realization. A Brier Score below 0.2000 represents elite international match calibration. 2. EXPECTED VALUE & HIT CONVERGENCE: Expected Hits = Σ p_i Net Performance Variance = Actual Hits - Expected Hits When Actual Hits > Expected Hits, the model displays positive variance and healthy conservatism. 3. GOAL EXPECTATION & DIXON-COLES ADJUSTMENT: P(X=x, Y=y) = τ(λ, μ) * (e^-λ * λ^x / x!) * (e^-μ * μ^y / y!) Corrected for low-score correlation (0-0, 1-0, 0-1, 1-1) in international tournament play. 4. CLOSING LINE VALUE (CLV): CLV = (Closing Odds / Stated Odds) - 1.0 Systematic positive CLV demonstrates statistical edge against market consensus pricing. 5. DUAL-PARAMETER BEST PICK MATRIX (CONFIDENCE & VALUE): Best Pick Index = P(Hit) * Edge(EV) Where: - Confidence Floor: Model Hit Probability P(Hit) ≥ 52.0% (statistically favored to win). - Value Floor: Positive Expected Value (EV) ≥ +2.5% over bookmaker consensus pricing. By maximizing the product of Confidence and Value, the engine eliminates low-probability underdog traps with deceptive edge while rejecting unbackable chalk favorites with negative expected value. 6. UNCERTAINTY FILTER & PASS PROTOCOL (NO-PICK DISCIPLINE): Quantitative models preserve capital and eliminate random-walk drag by withholding picks when outcome entropy is maximal or expected value is negative. Rather than forcing an arbitrary call on 50/50 noise, the engine issues an official PASS (NO PICK): - Match Result (1X2): PASS when top outcome probability P < 44.0%, or probability delta between 1st and 2nd choices Δ(P_1st - P_2nd) < 5.0% (dead-heat toss-up). - Goal Total (2.5 Line): PASS when 48.0% ≤ P(Over 2.5) ≤ 52.0% (parity coin-flip centered on handicap line). - BTTS & Corners: PASS when probability lands within the symmetric noise band [48.0%, 52.0%]. - Best Pick Hurdle: PASS if no market clears both the 52.0% confidence floor and +2.5% EV hurdle. Passed selections do not drag down realized wagers.
