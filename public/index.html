Forward Ledger Calibration Engine

International football prediction requires strict calibration over long horizons due to lower match frequencies and elevated variance compared to domestic leagues.

Expected Hits Calibration

E = ∑ p_i

Sum of model predicted probabilities. If Actual > Expected, the model is running in positive variance (lucky) or is under-confident. If Actual < Expected, the model is over-confident.

Brier Score (Mean Squared Error)

BS = (1/N) ∑ (f_t - o_t)²

Measures probabilistic forecast accuracy where o_t ∈ {0, 1}. 0.0 represents perfect foresight; 0.25 is equivalent to coin flipping.

Expected Value & Market Edge

EV = (P_model × Odds) - 1.0

Selections are only submitted if EV > 0 and the model probability exceeds the closing bookmaker implied fair probability by at least +2.5%.
